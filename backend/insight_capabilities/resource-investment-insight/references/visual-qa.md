# Insight 视觉与分析验收

这是后续工程接入的验收清单，不代表当前已经接入、调用 Qwen 或完成真实界面测试。记录每项“通过／不通过／未验证”，不把静态契约校验当作浏览器验证。

## 代表性场景

| 场景 | 证据输入 | 应看到 | 不应看到 |
|---|---|---|---|
| 有重点但不能直接定性 | 截图案例：900 的 2027 本范围计划投入 92,000，2025 本部门资源 30,000；2025 对 2024 Vol −10%、C3 −1%；无 2027 预测 | 六行摘要；围绕 900 的一个合并发现；同量纲金额比较条；历史信号；紧邻“跨两年比较，非同比”的说明及补充依据方向 | 92,000 与 −10% 共用一条数值轴；直接建议减投；无证据宣称高风险 |
| 没有突出事项 | 明确标为合成的完整证据，已配置检查规则均通过，预算准确对平 | 六行摘要与一句本轮总结；如用户选结构方案仍可按需要看构成；没有重点就不凑长文 | 六张重复绿卡；强制三张图；将未检查领域概括为全部正常 |
| 依据不足但仍有可用事实 | 明确标为合成的证据：存在预算与分配事实，但部分对象缺历史 C3／历史总资源或计划预测 | 受影响维度标依据不足；明确缺口与排除人数；预算和结构事实照常可读；不具备四象限条件时提供短表 | 空散点被当零值；缺少权限的数据出现在 tooltip；为了画图补点或猜测阈值 |

截图案例只是可追溯的演示输入，不代表生产数据已核验。后两个场景在 fixture 与页面上都应标“合成测试数据”，不能标“Qwen 实际生成”，除非确有对应调用记录。

## 数据与结论检查

- [ ] 六维摘要恰好六项且 ID 唯一，均有状态与一句结论；权限不足和证据不足不会被填为 clear。
- [ ] 图块选用的 dataset_id、所有 fact_ids 都属于本次授权证据；改角色、部门或 Initiative 后旧引用失效。
- [ ] 图形类型仅使用契约中的 `comparison / composition / ranked_bar / quadrant / table`；同一数据切换批准图形时，计算口径、分母、样本范围和时期保持一致。
- [ ] `dataset.scope_id` 与 context scope 一致；整体历史 Yield 可作为当前范围获授权的只读汇总引用，但不得同时暴露未授权的跨部门资源明细。
- [ ] 文字关键金额、差值、占比、单位、时期与事实一致；独立复核至少一个有影响的比值，不能只比较两个调用同一 helper 的输出。
- [ ] 92,000／30,000 的差值为 62,000，增幅约 206.67%；文案明确其为 2027 计划对 2025 历史的跨期比较，不能叫同比或预测回报。
- [ ] 预算 1,962,000 = 经销商分配 1,926,964 + 其他预算安排 35,036，差额为 0；两类占比分母均为 1,962,000，四舍五入后约 98.21% 和 1.79%；不将后者称作已分配经销商。
- [ ] 92,000／1,926,964 约 4.77% 是“经销商分配额内占比”；改用总预算分母则约 4.69%，标签必须随口径变化。
- [ ] 零、缺失、空集合、历史分母为零分别测试；缺失既不能参与中位数也不能变成图上零点。
- [ ] 四象限使用完整候选队列经过明确条件筛选后的可比样本；样本数、排除原因、阈值方法可见；中位数不是只对 Top N 重算。
- [ ] 阈值相等、全部同值、重叠点、仅 1 个有效点、所有点不可计算都有可理解结果；无意义分组降级短表，不能给出虚假的四象限结论。
- [ ] 合并类别前证实互斥和可加总；层级父子、共享对象、跨部门无权限明细不发生重复统计或泄漏。
- [ ] 超额预算不被 100% 封顶条隐藏；红色提示包含准确超额金额和实际占比。对平后仍保留其他预算安排分布。
- [ ] “低 Yield”“高投入”是相对描述还是配置规则有清楚区别；没有预测或因果证据不输出必然增减投、确定因果或确定 ROI。

## 界面检查

- [ ] 同一个 Insight 页面，方案选择与结论状态不同层级；没有“有问题／没问题／无法考证”三个 Sheet，没有用户提示词编辑器。
- [ ] 六行摘要默认显示；详细说明可以展开，摘要本身不能收起为默认不可见。重点发现不是六个固定同等高度卡片。
- [ ] 在 430px 侧栏、至少 900px 展开容器、320px 窄屏分别检查文字、金额、图、注释及展开后的表格；记录实际容器宽度，不只检查浏览器窗口宽度。
- [ ] 核心占比至少 16px，可一眼读出；文本不溢出、数字不中途断开、长标签可换行；320px 无意外页面横滚。
- [ ] 对比条从零开始、同轴同单位；金额、刻度、标签和 tooltip 的元／万元换算一致；散点两个轴均有可见量纲、范围和阈值。
- [ ] 颜色有重复编码：文字状态、图标、标签或形状；灰度下仍能识别重点与比较系列。黄底深字、红色仅用于确证错误、绿色仅用于算术对平。
- [ ] 重要限制紧邻对应图；没有把跨期、权限、缺失说明藏在总页脚或 hover；导出截图仍保留必要口径。
- [ ] 每个散点可通过鼠标和键盘或等效列表选择；同坐标多个对象均可查看；读屏能获得对象身份与两轴值。
- [ ] 分析方案、展开、定位事实、选择对象的焦点顺序合理，焦点清晰；tooltip 不是获取数据的唯一途径。
- [ ] 加载、空结果、图形降级、错误、切换范围和旧结果失效状态明确；标题与内容快照一致，无误导性旧结论。
- [ ] 三种方案可使用不同数量及类型的块；接受“没有图”的合理结果，不强制输出三张图或每维度一张图。

## 提示词自由度与回归

- [ ] 同一组事实允许两份不同措辞／顺序／块数量的有效结果；两份均可通过校验与渲染，不以固定句式为验收标准。
- [ ] 修改方案提示词的关注点、语气和分析顺序，不需要修改前端；仅新增图形类型或改变证据结构时才调整契约。
- [ ] 对未知 dataset_id、未授权 fact_id、模型 HTML、额外字段和无效状态进行拒绝或明确降级；不能悄悄删掉错误后显示“分析成功”。
- [ ] 提示词原文、方案版本、契约版本和证据快照可追溯；预览中的合成内容与真实调用结果有明确标记。

## 验收记录模板

```text
测试日期：
能力包／方案版本：
证据 fixture 或快照 ID：
模型调用：未调用／模型 ID 与请求记录 ID（不含密钥）
代码校验：通过项与未覆盖项
渲染检查：实际宽度、场景、截图位置
交互检查：方案、展开、键盘、点选择、范围切换
数字独立复核：抽查项与计算结果
剩余问题：事实错误／可读性／缺证据／未验证，分别列出
结论：本次检查范围内可测试／需修复后测试
```

规则来源：`data-analytics:validate-data` 的正常 authoring 验证深度和 `data-analytics:visualize-data` 的真实标记、单位、分母、零基线、交互与窄屏检查；本清单仅覆盖本能力包，不扩大为全工程审计。
