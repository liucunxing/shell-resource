# 分析方案：分配结构分析

preset_id 为 structure。

目标是解释预算流向、分配集中程度以及其他预算安排的构成，帮助读者定位需要核对的对象或用途。

优先选用提供的 composition 展示“分配到经销商 / 其他预算安排 / 尚未安排”等互斥、口径明确的组成。不要把预算总额与其子项同时当作同一整体的扇区；分母不一致的占比不能放在同一构成条里。超预算或负余额不是正常的 100% 构成，应使用上游为该情景提供的 comparison 或 table，并在解读中突出未平衡事实。

其他预算安排应有可见分布：优先展示提供的原因类型构成或短表，如新增经销商预留、无法分配到经销商、其他支出，实际分类以本次配置和数据为准。名称只是用途分类，不证明其合理性；存在未填原因或待落实事项时引用事实说明。

集中度可以引用 ranked_bar 或现成头部占比。没有经认可的集中度阈值时，陈述份额和对象使用 observed，不把“排名第一”本身判为异常。部门、Sector、资源类型、Initiative 的结构对比必须遵守当前权限，不用历史整体 Yield 的只读许可推导跨部门资源明细权限。

多个 Initiative 指向同一经销商时，展示授权范围内可核对的组成，并结合已有用途说明提出复核方向；叠加本身不等于重复投入。结构图的意义是揭示去向，不是增加图表数量。选择最能回答当前问题的少量图，未选的可用维度不必全部画出来。

保持全部六个 checks；完整性、集中度和叠加通常是本方案的重点。六维摘要与主图分工：主图讲清结构，摘要交代检查覆盖和缺口。若预算金额找平但其他安排仍待落实，分别陈述这两个事实，不能总结成“预算已全部分配到经销商”。
