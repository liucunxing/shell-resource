# 版本启停与移除验证（2026-11-17）

本次按用户确认调整为每行固定显示「编辑、移除、启用、停用」，推送但不部署，无新增数据库迁移。

| 操作/状态 | 当前行为 |
| --- | --- |
| 编辑 | 修改版本信息，保留启停状态、分配及部门确认 |
| 启用 | 本版本可分配；原子停用其他版本，全局最多一个启用版本；原部门确认锁不自动解除 |
| 停用 | 只关闭分配窗口，已有草稿、提交、部门确认和原权限内的可见数据保留 |
| 移除 | 启用中禁止；存在提交记录需额外确认；软删除后退出业务列表，数据保留供审计 |
| 管理员配置 | 用户明确确认停用后仍可改项目预算、Owner、项目启用状态；不自动启用版本，变更影响仍按原规则要求重提 |
| 停用后的分配 | Owner、兼任 Owner 的部门负责人不能保存、导入或提交，部门不能提交或撤回；管理层、管理员不因此获得分配写权限 |

旧 API 可用 `published=false` 隐藏已启用版本，现已禁止；需要停用时仅设置 `open=false`，需要从列表移除时走有确认保护的移除接口。前端保存/提交遇到 HTTP 409 时保留服务器原因和当前编辑，不再一律声称被其他人更新。
