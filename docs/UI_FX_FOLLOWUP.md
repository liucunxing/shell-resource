# 界面与汇率调整（2026-11-15）

## 已确认并实现

- 历史C3已是美元。历史投资当前源端也已转为美元；后台 `historyInvestmentExchangeRate` 默认1。读取时执行：历史费用源金额 ÷ 汇率 = 美元。未来源改为人民币时可填7.2等已确认汇率；不重复换算C3、不改PG源值。费用与Yield随配置刷新。
- 配置采用现有管理员权限、修订冲突保护及前后值审计；必须为有限正数，导入参考数据保留配置。当前是统一换算参数，作用于全部历史年份和费用类型，不是自动逐月汇率。
- 规划预算、预留、分配仍为人民币；历史费用显示千美元。汇率1只表示历史源已为美元，不能作为规划人民币兑美元汇率。历史USD与规划CNY的差额/倍数暂不计算，显示币种不同及缺规划汇率的原因。
- 用户最终确认负费用正常计算：原始负项参与净额，影响历史总额、费用构成金额与Yield分母；试算只将最终非正权重按0处理，净投资不正时Yield显示“—”。负项构成图不画误导性的正向占比。已保存规划金额不随历史配置改变。
- 同编码跨Sector按两个业务身份，家数/集中度按Sector+编码统计；跨Initiative同身份去重。
- 已有UI修改保留：预算卡片明确“万元”；勾选经销商保持滚动位置；投资/C3双点比较去掉底色和填充，黄点/白点有描边，重叠时仍可辨认。
