# 管理员模拟用户视角

管理员可在“管理后台 → 人员与权限”找到用户，点击“模拟查看”。工作台按该用户当前角色、部门、业务线和项目归属加载；管理层仍只查看已同步快照。页面顶部持续显示目标用户和“只读”标识，点击“返回管理员”恢复管理入口，可继续选择其他用户。

模拟仅供查看。保存、同步、导入、配置修改、分析生成及问数启动在此期间停用；已保存的分析、数据表和同步历史仍按目标用户权限读取。真实管理员登录身份始终保留。切换时清空旧数据、分析组件和问数窗口，刷新页面后不保留模拟身份。

只有启用的管理员可发起模拟；停用、未配置或权限无效的目标用户不能进入。后端每次请求重新确认管理员和目标权限，前端隐藏按钮不是权限边界。该功能沿用现有帆软邮箱入口和 Portal 会话入口的认证边界，不代替真实用户的 SSO 登录验收。

接口契约见 [接口文档](../backend/docs/接口文档.md)。此功能不涉及数据库结构变更。
