# 历史数据口径与筛选修复（2026-10-22）

本文为历史验证的公开摘要。真实用户与源业务快照明细已移除；保留原验证方式、失败记录和发布边界，不把真实数据回放改称合成数据验收。

历史验收发现，受测对象已有经营历史，但部分资源金额受权限限制。两者需要分开表示，不能把资源金额不可见等同于经营历史缺失。公开记录已移除真实经销商名称、编码、销量和财务数值。

当时按获授权账号的实际权限核对经营历史与资源金额可见范围。资源金额受限不表示整体历史 Yield 缺失，也不能据此扩大资源查询权限。以下是该次修复的技术记录，不公开具体账号或权限快照。

本次修改：

- 历史接口增加restrictedResources2025资源名称列表，不带受保护金额。投入比较以resource_restricted区分未授权金额与真实空值；页面显示“未授权”“历史金额未授权”“无法比较”，并说明不能据此判断销量或Yield缺失。MRD金额不反算、不补查、不扩大权限。
- Yield为0不进入高低Yield案例、Yield明细、四象限和中位数计算；原始零值和实际分配保留，销量/C3趋势、投入变化及预算合计不受影响。全零时说明零值不参与，不谎称历史缺失。
- 模型提示词将资源权限限制放在limitations，不把已有经营趋势降级为limited；校验拒绝把已有经营历史的对象笼统称为“无历史数据”。修复提示定位内容块下标和允许状态。
- 管理员“预算与Owner映射”增加Initiative名称模糊搜索，忽略大小写和首尾空格。显示匹配数量，零匹配有提示；筛选不改变配置导出、预算总额或待编辑对象。
- 历史数据增加业务线筛选：全部、PCMO、CRTO、B2B、OEM。与编码/名称条件取交集；切换条件重置页码，CSV仅导出筛选结果。

能力包版本0.3.4-engineering，不需要数据库迁移。旧Insight保留，发布后需要重新生成才能使用新口径。

使用当时获授权的冻结业务快照完成后续两轮真实 Qwen 回放，核对经营历史与资源金额权限分别处理、有效历史值保留及受限资源金额隔离。账号、经销商标识、源业务数值及私有快照路径已从公开记录移除。该回放使用真实授权数据，与合成测试数据无关。

首轮4次回放中有1次内容块状态校验失败：模型把权限限制作为limited块挂在允许observed的trend维度，二次输出未修正。已针对该原因补充提示和准确的校验修复信息，再进行上述完整两轮复测。不能把首轮失败隐藏为首次全部成功。

没有进行线上部署或浏览器交互验收。推送不等于发布；上线后仍需验证生成和保存读回。
