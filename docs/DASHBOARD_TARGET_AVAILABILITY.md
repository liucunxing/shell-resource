# Dashboard Target 空值排查

2026-11-18：管理层资源大类详情的 Target 空值有两个独立原因。

1. 本机 8020 预览进程仍运行 2026-11-15 加载的旧后端，源 `sourceTarget*` 有值，但展示用 `contract*` 和 `phasing*` 被旧批次确认门控清空。磁盘代码已修复不代表进程已加载；重启本机预览后，真实 API 与当前源值投影一致。此操作不代表服务器部署。
2. 详情 `historicalDetailTotals` 使用完整合计：当前范围任一业务身份的 Target 缺失，就不返回完整总额。源 NULL 仍须保留，不能补零或跨年份借用。

详情现保留完整合计，同时对缺失场景显示覆盖家数及已知值小计（明确标注“非完整合计”）。全部缺失不显示零小计；零和有限负值正常计入已知值。单位仍为源 L、展示 KL。

范围沿用当前已确认项目的经销商名单，按 Sector 与经销商身份去重，包含已选未获配对象。搜索和分页不改变覆盖或小计。期间切换使用对应年度字段；Phasing、Yield、费用权限和其余完整合计不变。

排查顺序：只读核对源字段 → 正在运行的接口 `sourceTarget*` 与 `contract*` → 当前业务范围的完整性 → 页面格式化。批次期间确认状态与数值可用性分开，不能为了恢复显示而自动续期确认。

验证：79 个前端测试文件、442 项测试通过，TypeScript/构建与 bundle 检查通过。真实 PG 全量 1,489 个业务身份只读对账通过；重启后的本机 API 恢复 2025/2026 Target 799/795 条、Phasing 535/695 条。管理层 SP&A 详情已检查两期覆盖提示、KL 换算，以及 1280px/390px 视口无横向溢出。未改源表、确认配置或业务记录，未部署服务器；本机预览不作为真实 SSO 或业务 UAT 证据。
