## 算法与配置边界

- **集中度（§12.1，L35–36）**：取名单并集内有历史的对象，投资金额按百元取整比较后降序；同值按产出降序，再按编码升序。Top 20/50/80% 共用排序；金额均分不应误判为集中。总体匹配但内部项目超标，另列内部集中项目。
- **叠加（§12.2，L37）**：项目金额先按经销商合并；历史贡献按同一身份去重，不能随项目数重复累加。PG 同编码多组织的身份口径另见待确认项。
- **试算（§12.4，L39）**：`T=预算−预留`，非负整数元；使用所选期间 Vol、C3 或历史总投资作权重，**负权重归 0**，无历史对象为 0；总权重 0 时不能试算。先对 `T*w/Σw` 向下取整，再按余数降序补足元，最终和必须等于 T。该负值规则只明确适用于试算，不授权改写历史原值或统一抹平所有分析负数。
- **配平（§12.5，L40）**：勾选对象按当前金额降序、同额按编码排序；每家变化 `trunc(P/k)`，前 `abs(P−trunc(P/k)*k)` 家再加 `sign(P)`。例如 P=1001、k=3 为 +334/+334/+333；P=−5、k=2 为 −3/−2。结果为负或未选对象时阻止。
- **阈值（§13.6，L41）**：集中度 5/10pp，叠加 3/6pp；允许 0–100，步长 0.5，黄线必须小于红线。YTD 截止配置 1–12，默认 10；配置修改应持久化、检查修订冲突并留审计。
- **服务端复核（§13.2、§14.3，L41）**：提交、看板、导出使用统一规则或由服务端复核；前端预览不能替代权限、预算、版本、名单、非负整数与修订校验。
