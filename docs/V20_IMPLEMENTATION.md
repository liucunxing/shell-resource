## 组织页

“我的投入组合”和相应部门组合页的Tab为“按SD/RSM看”，切换后汇总、提示、Initiative矩阵和组织下钻全部使用所选维度。

| 分组 | 内容 |
|---|---|
| 本次投资 | 分配/全部、投资金额（万元）、家均（万元）、投资金额占比 |
| 历史Actual | Delivery Vol占比、C3占比、两条历史占比图，独立浅底色 |
| 投资金额占比 | vs Delivery Vol、vs C3、判断，差值为pp |
| 较上版 | 当前金额−来源版本同一Initiative集合的可见提交金额，带符号万元 |

“全部”是授权Sector内该组织的完整经销商主数据；历史分母是当前名单并集，包含分配为0的已选经销商。仅改投资金额时，Actual数值、占比、图形和刻度均不变；改名单或历史期间会改变历史范围。没有可比的来源提交时显示“—”，不冒充0；上版存在、本版退出的对象保留减少金额。

拆分工作台第三步“投入结构”使用同一四组列序，第一列分母改为当前 Initiative 名单。占比对照图按 V17 样式画投资金额、Delivery Vol、C3 三条横条，并在合计行显示投资金额占比极差。黄色投资条随金额更新，浅蓝和深灰的历史条及共用刻度不变。较上版按来源版同项目最后提交金额比较。

## 历史费用权限

所属部门决定费用大类上限：MKT→MRD/SP&A，ICE→ICE Rebate/SP&A，Capex→Capex。部门配置、个人配置只能进一步收窄；管理层、管理员不因角色而越过上限。缺少有效所属组织时不提供明细。

历史总额、Yield、历史投资占比仍公共可见，因此可见费用之和不一定等于总额。后端在序列化前裁剪费用；表格、抽屉、原始数据导出和Insight使用同一授权结果，不能把所有费用送到浏览器后再隐藏。

## 第一步预留核对

用户在批准V20后追加恢复V17的“已核对本版预留”。第一步未勾选时不能点下一步，也不能用页内Tab或恢复步骤绕过；草稿与提交的批量提交同步检查，按钮状态与发布前均再次校验。已提交只读项目可继续浏览。核对按用户、项目、规划版本隔离，预算或预留金额/原因变化后失效。同浏览器会话刷新可保留，属于页面流程确认，不是跨设备签署或审计记录。V20独立原型与工程同时补齐。

## 抽屉与提示

核对经销商、Initiative、资源大类、SD/RSM组织、试算方法/原因，以及健康分析名单入口。详情保留当前业务范围、版本、期间；内层下钻可以返回上层，关闭恢复焦点，Escape及窄屏可用。预算写入、试算采用、导入和提交等操作继续通过原有校验与确认，不能因分析抽屉绕过冻结或只读模拟权限。

| 抽屉入口 | 工程内容与边界 |
|---|---|
| 经销商 | 当前规划资源环图、项目来源、历史Actual/授权费用、期间切换；保留Sector业务身份 |
| Initiative / 资源大类 | 名单、累计集中度曲线、Top20/50/80、SD/RSM结构；继续下钻锁定原项目和名单范围 |
| SD/RSM | 所选维度的组织详情、项目与经销商结构；与父页切换联动 |
| 试算方法/原因 | 当前方法、计算依据、独立参考期间；查看不采用、不写回草稿 |
| 健康/Top名单 | 当前名单及Initiative同刻度堆叠投入条；不混入其他项目 |
| 版本变化 | 两版本各自最后提交快照，预算/投资/预留/经销商差异，汇总到项目再返回；无提交或未确认不能当0 |

历史费用权限不足四类时不画完整历史投资环图；公共总额不以已授权费用之和替代。我的Initiative及草稿列表的“编辑/继续拆分”仍为进入工作台导航，原型也不是详情抽屉入口。

## 口径更正

- PPP是V19实现时误加的占位列，供应商说明及会议没有定义独立目标指标。V20取消该字段、提示、导出和API缺项要求，不再向源端索取“PPP/销售目标”。经销商target是Phasing的独立分母需求。
- Sellin销量/C3按季度更新；刷新频率不等于数据业务截至月。Actual、费用和target各自提供覆盖期间。
- 用户在本轮确认当前PG批次销量、C3、费用均至2026年9月并已同期对齐，下一次预计2027年1月更新。时间字段延期补充，本批使用明确确认，不再列为当前缺数；新源批次不能自动沿用旧确认。
- 历史C3和当前历史费用源为USD；历史费用÷管理员汇率转为USD，汇率暂保持1。规划预算与分配为CNY，元/万元显示。
- 负费用正常参加净额；仅最终试算权重截为0。Yield无x/倍后缀，负值、缺失及无效比率显示“—”；汇总先求和再除，不改变负费用原值。
- 同编码跨Sector算不同经销商；跨Initiative在同一Sector身份内去重，不能重复装载同一笔源业务。
