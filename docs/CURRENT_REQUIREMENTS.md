## 规划与协作

| 范围 | 当前要求 |
|---|---|
| Owner | 三步完成经销商与其他预算拆分；草稿可暂不平衡，正式提交必须平衡；提交后冻结，只在被退回后重新编辑 |
| 部门负责人 | 当前部门全部 Initiative 提交后才可确认；撤回仅取消部门确认，Owner 提交仍保留；定向退回按项目、Owner 或全部门执行，必须填写原因 |
| 管理层 | 分配与分析只纳入部门已确认快照；预算仍可见，不能把未确认草稿计入组合 |
| 规划版本 | 独立创建、发布、截止与关闭；新版本只复制最后提交快照，不复制未提交改动，版本间状态隔离 |
| 对比 | 保留来源版本与当时 SD/RSM 归属；退出组织保留零值及相应 -100%，不能仅取新版本交集 |
| 经销商名单 | 纳入零投入经销商，跨 Initiative 按对应身份去重；检索、排序、分页不改变历史比较分母 |
| 其他预算 | 受保护原因保持固定；停用不删除已有金额，自动找平不能改写人工理由 |
| 用户权限 | 所属 Sector/Department 与授权业务范围独立；历史费用按用户覆盖 > 所属部门 > 角色，缺归属不展示明细；公共历史总额独立于受限明细 |

该范围目前未看到 Vol、C3、费用、合同量、PPP、业务截止月或汇率字段。应用现有 Service Principal 认证返回 `401 invalid_client`，因此上述内容存在性核查不能证明应用身份可读。视图可能按身份改变结果，不能把个人结果作为 SP 读取结果。

应用只可使用它的 Service Principal 对应且获授权的 schema。其他 schema 的候选源不属于可直接集成范围；如需使用，由数据负责人提供到该范围后，再以应用身份验收。禁止个人凭据回退和自行扩权。

## 指标口径要求

2026-11-15 补充：用户确认 PG 历史表 Vol 为 L，历史C3为USD，历史费用/投资及规划投资为CNY（用户后续明确，覆盖先前笼统的$说明）；2026 截止 9 月仅为用户暂估，源表没有业务日期或截止月份列，不应写成已证实。全量数据核查及多 SD/RSM 记录说明见 [PG 历史数据评估](PG_SELLIN_ASSESSMENT.md)。应用按 Sector＋编码＋SD＋RSM 保留独立身份，不直接删除或任意合并同编码的组织记录。

- Actual 与费用必须各自带真实业务截止月；刷新时间、最大日期、其他来源月份不代表完整性。
- V2.0 已定义管理端 YTD 截止配置为 1–12、默认 10。配置值与真实 Actual/费用覆盖月份分别表达；管理员改配置不能把未知来源月份改成“已确认”。
- 缺失显示未提供，不能补零、伪造最新月份、默认全年或默认年化。源值与来源元数据需同批返回。
- 合同量显示 KL，Phasing = Vol / 合同量，合同量必须 >0；PG 缺合同字段是数据供给缺口，公式本身已经明确。V17/V19 已明确合同采用全年签署量；工程应读出已提供合同，真实PG缺字段时保持空值。
- Yield = C3 / 同期完整历史总投资，C3 与总投资均须 >0；汇总先求和再除。YoY = (2025−2024)/2024，基期 ≤0 显示“无基期”。不得直接把数学上无效的源 Yield=0 当有效比率。
- 试算权重使用所选期间 Vol/C3/历史投资，负权归 0；总权重 0 时阻止试算。此规则不授权改写源负值，也不等于全部分析都采用截零口径。
- V19 已明确 PPP 是目标 Vol（KL）/C3（K$）列，当前缺真实目标来源和字段映射，保持待配置，不用合同或 Actual 代替。集中度、累计曲线、叠加与 SD/RSM 产出占比使用截零后的 Vol/C3；无正 Vol/C3 历史对象不参与比较；历史明细与历史金额汇总保留原值。负Yield已明确显示“—”，所有Yield不带x；负费用正常采用有符号净额与图表保护。剩余缺数据见确认清单。
- C3为USD、历史投资归一为USD、规划投资为CNY。Yield保留C3美元÷历史投资美元原数值，是统一美元口径的表现参考；不能标成未来回报。管理员配置 historyInvestmentExchangeRate，默认1；历史源费用÷汇率=美元，规划人民币不使用此汇率。
- 当前 PG 历史与更广 Databricks 范围的汇总尚未对账一致，不能静默覆盖或仅借用其月份/币种元数据。
