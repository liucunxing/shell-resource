## 规划与协作

| 范围 | 当前要求 |
|---|---|
| Owner | 三步完成经销商与其他预算拆分；草稿可暂不平衡，正式提交必须平衡；提交后冻结，只在被退回后重新编辑 |
| 部门负责人 | 当前部门全部 Initiative 提交后才可确认；撤回仅取消部门确认，Owner 提交仍保留；定向退回按项目、Owner 或全部门执行，必须填写原因 |
| 管理层 | 分配与分析只纳入部门已确认快照；预算仍可见，不能把未确认草稿计入组合 |
| 规划版本 | 独立创建、发布、截止与关闭；新版本只复制最后提交快照，不复制未提交改动，版本间状态隔离 |
| 对比 | 保留来源版本与当时SD/RSM归属；退出组织保留减少金额。V20组织页“较上版”显示带符号万元，不用百分比代替 |
| 经销商名单 | 纳入零投入经销商，跨 Initiative 按对应身份去重；检索、排序、分页不改变历史比较分母 |
| 其他预算 | 受保护原因保持固定；停用不删除已有金额，自动找平不能改写人工理由 |
| 用户权限 | 所属组织与业务授权范围独立；费用明细按所属部门大类上限，再以部门/用户配置收窄。角色不扩权，缺有效归属不提供明细；完整历史总额、Yield、占比公开 |

所有应用控件以共享shadcn/ui为实现标准，**已确认V20是完整视觉与交互基线**。必须保留布局、配色、字号密度、导航顺序、Tab、图表、表格与抽屉交互；不以组件迁移为理由重新设计。

基线为工作区 `迭代需求/Distributor_Resource_Studio_HiFi_V20.html`，SHA256 `68336B37815ECD18DD8B12C6E6579B918CA8EDABDB3DDF100C466AE5B895EED0`。按最终CSS/JS覆盖呈现。主操作黄色 `#FBCE07`，顶部深灰蓝 `#303B44`。经销商分配明细的表头按用户要求恢复V17，保留V20流程和权限。

“按SD/RSM看”必须联动汇总、提示、矩阵和下钻。四组依次为本次投资、历史Actual、投资金额占比差值/判断、较上版金额。历史块独立底色，Vol/C3占比图不随投资金额变化。经销商/项目/资源/组织/方法入口均提供可操作详情抽屉，保持当前范围、版本和期间，支持返回、Escape、焦点恢复及窄屏。

拆分工作台第三步“试算、微调与提交”的投入结构同样采用四组。当前项目的“分配/名单”按有正投入人数和勾选人数显示，后接投资金额、家均和占比。历史Actual三列为Delivery Vol占比、C3占比、V17样式的三条占比横条，黄为当前投资、浅蓝为Vol、深灰为C3。仅改金额时，黄条更新，历史两条及刻度保持不变。差值组同时显示相对Vol、C3的百分点差和判断。较上版显示与来源版同项目最后提交的有符号万元差。经销商分配明细纵向滚动时冻结两层表头，获配项目以横排名称显示。

Owner 主导航顺序：我的 Initiative → 拆分工作台 → 我的投入组合 → 草稿与提交。组合页采用同层级 Tab：Owner 五项、部门六项、管理层五项；管理层第 3 项为“叠加到经销商”，Owner 不额外添加版本变化页。模块、图形与权限细节按原型角色分别还原，不能共用一套简化看板代替。

较大交互取舍可请用户选择；调整后需提供原型/工程同角色、同视口、同页面状态的对照证据，再请用户确认。

## 指标口径要求

用户最终确认：PG Vol为L，历史C3和当前历史费用源为USD；规划投资为CNY。历史费用除以管理员汇率转为USD，目前保持1。Sellin按季度更新。当前数据缺项及源质量只采用本轮只读扫描，见[PG评估](PG_SELLIN_ASSESSMENT.md)，不沿用旧“2026费用全空”的判断。

用户随后明确：当前这批销量、C3、费用均累计到2026年9月且已对齐，下一次预计2027年1月更新。当前按同期数据处理；源端时间标记列为后续补充项。本批人工确认只适用于当前源快照，新一批需重新核对或使用源端明确期间字段。

- Actual 与费用必须各自带真实业务截止月；刷新时间、最大日期、其他来源月份不代表完整性。
- V2.0 已定义管理端 YTD 截止配置为 1–12、默认 10。配置值与真实 Actual/费用覆盖月份分别表达；管理员改配置不能把未知来源月份改成“已确认”。
- 缺失显示未提供，不能补零、伪造最新月份、默认全年或默认年化。源值与来源元数据需同批返回。
- 经销商target显示KL（兼容字段contract*）；用户确认target_2025/target_2026单位L，分别为2025全年和2026年1–9月，现已按独立批次确认接入，见[对账](DEALER_TARGET_INTEGRATION.md)。Phasing=Vol/同期间经销商target，target>0；9月YTD对应1–9月target。缺字段或期间不明时保持空值；不拿销售SD/RSM目标或全年目标替代同期目标。
- Yield = C3 / 同期完整历史总投资，C3 与总投资均须 >0；汇总先求和再除。YoY = (2025−2024)/2024，基期 ≤0 显示“无基期”。不得直接把数学上无效的源 Yield=0 当有效比率。
- 试算权重使用所选期间 Vol/C3/历史投资，负权归 0；总权重 0 时阻止试算。此规则不授权改写源负值，也不等于全部分析都采用截零口径。
- PPP是V19误加占位，V20已取消，不再要求提供PPP或销售target。集中度、累计曲线、叠加与SD/RSM产出占比使用截零后的Vol/C3；无正产出对象不参与比较。历史原值及负费用保留有符号净额；负Yield显示“—”，全局无x/倍后缀。
- C3为USD、历史投资归一为USD、规划投资为CNY。Yield保留C3美元÷历史投资美元原数值，是统一美元口径的表现参考；不能标成未来回报。管理员配置 historyInvestmentExchangeRate，默认1；历史源费用÷汇率=美元，规划人民币不使用此汇率。
- 当前 PG 历史与更广 Databricks 范围的汇总尚未对账一致，不能静默覆盖或仅借用其月份/币种元数据。
