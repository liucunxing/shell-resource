# 缩放、弹窗与抽屉检查（2026-11-16）

用户要求覆盖1920×1080、150%缩放及帆软嵌入后的可用空间。以本地V20合成数据分别在实际安装的Edge、Chrome中验证；没有更改客户操作系统DPI、没有模拟真实SSO，也没有写生产业务数据。

## 修复

- 共享Dialog采用有高度上限的纵向布局；新增DialogBody作为独立内容滚动区，标题与底部操作区不随内容滚走。
- 接入个人信息、人员维护、规划版本/部门流程、组合明细、编辑器试算/导入/历史等弹窗。保留原确认、取消、禁用和权限逻辑。
- 弹窗宽度以当前文档视口计算，底部按钮可换行；低于600像素高度时收紧内边距。长标题换行并为关闭按钮留位。
- 两类详情抽屉共享样式限制标题区高度，长标题可滚动；正文独立滚动，底部操作区保留。既有表格仍在自身容器内横向滚动，不缩小数据字号或裁掉列。

## 浏览器检查

| 场景 | 检查尺寸（CSS像素） | 实际检查 |
|---|---|---|
| 1920×1080 / 150%的逻辑空间 | 1280×720 | 页面及浮层边界、内容滚动 |
| 浏览器工具栏、帆软页签占用高度 | 1280×600 | 标题、底部操作、关闭可见性 |
| 系统150%基础上继续放大/缩小嵌入区域 | 853×400 | 长内容到底、键盘Tab约束、Escape关闭 |

页面覆盖Owner首页、拆分三步、投入组合各Tab、草稿与提交，部门组合/确认，管理层总览/集中度/叠加/明细/版本变化，以及管理员六个入口。Chrome共96组页面/尺寸检查，无整页横向溢出。

浮层覆盖13种入口，每种3个尺寸：个人信息、新增人员、创建规划版本、撤回发布、三种试算对比、试算经销商预览、拆分依据、经销商详情、SD组织详情、组合全量清单、撤回部门确认、资源大类详情、集中度曲线下钻。Edge和Chrome各39组，检查窗口边界、滚动前后标题/底部位置、可用按钮遮挡、Tab焦点约束及Escape关闭。集中度另检查四维切换和浮层内口径提示。

测试数据仅有一个已发布版本，版本变化页的空状态已检查，双版本差异抽屉没有用真实双版本数据打开；其使用本次统一修复的抽屉容器。导入和历史弹窗通过编辑器/Workflow共享容器获得修复，本轮未逐一上传文件触发所有错误分支。未执行生产保存、提交、部门确认或版本状态变更。

浏览器执行脚本、逐项尺寸结果与截图保存在本地忽略目录`output/playwright/`：`pages-audit.*`、`overlays-audit.js`、`overlays-edge.log`、`overlays-chrome.log`和`overlay-*.png`。429项前端测试、构建及包体检查通过。客户实际帆软会话与操作系统缩放仍需现场确认，逻辑视口验证不等同于客户UAT。
