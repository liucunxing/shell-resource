# 管理员按用户视角试用 Insight

管理员打开Insight后，先选择用户，再选择分析范围和方案。Owner可选全部负责项目或单个项目；负责人可选授权部门；管理层使用各项目最新同步结果。页面使用后台当前权限计算出的范围，不把管理员看到的全量数据当成目标用户的数据。

全局提示词仍在同一页面编辑。保存后再点“试用分析”，结果标明使用的提示词版本；旧试用结果遇到提示词更新会提醒重新试用。切换用户、范围或方案时清空上一份试用结果。试用期间不能切换或修改提示词，重复点击不会重复请求。

试用保持管理员登录身份，不切换邮箱、不写入或覆盖用户的Insight，也不修改预算或同步记录。后台只允许管理员调用；目标用户必须启用。调用Qwen后再次检查管理员及目标用户是否仍有权限。无权查看的历史资源金额仍不进入投入对比，历史整体Yield按原规则参与分析。

新增GET/POST `/api/v1/workbench/insights/preview`，复用正式Insight的范围选择、事实编译、Qwen调用、校验和生成后授权复查。提示词仅取本年度已保存的global版本。日志增加`mode=admin_preview`及管理员actor_hash，原目标user_hash和请求编号保留。不需要数据库迁移。

验证：新增7项后端测试覆盖Owner/负责人/管理层实际工作稿和同步数据、资源列限制、全局提示词优先、结果不落库、非法范围、停用用户、非管理员请求及生成中双方撤权。完整后端335项通过。新增前端测试覆盖选择用户入口、禁用状态、接口传参和不切换登录身份；原管理员全局生成断言已按新需求更新。

最终前端35个测试文件、162项通过，TypeScript检查和生产构建通过。Ruff检查通过；构建仍有既有大文件体积提示，不影响构建成功。

真实Qwen使用此前已授权的liucxs快照，经过新增试用服务调用综合体检和四象限，分别16.290秒、19.781秒通过；结果有目标用户标记且内存仓库无新增Insight。管理员操作身份在本地回放中为测试身份，真实身份鉴权由上述隔离SQLite及HTTP测试验证。本地记录：`output/insight-admin-preview-qwen-20261022-143826`。本次未部署、未进行线上浏览器交互验收。
