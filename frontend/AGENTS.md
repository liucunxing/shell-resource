## 组件与样式

- 统一 React 19 + shadcn/ui（Radix）+ Tailwind；以 `package.json` / lockfile 为实际版本依据。TypeScript 用于新增公共组件；现有业务 JSX / JS 可渐进迁移，不声称 `allowJs` 等于完整类型检查。
- `src/components/ui/` 保存共享 shadcn 组件，`components.json` 保存生成约定；页面通过组合组件实现业务，不复制粘贴另一套基础控件。
- 按钮、输入框、选择框、复选框、表格、标签、卡片、提示、Tabs、Dialog 等使用对应共享组件。简单选择可用 shadcn `NativeSelect`，保留浏览器选项和原有表单事件语义。
- 用户已确认的V20完整原型是视觉基线，批准SHA和差异见[V20同步说明](../docs/V20_IMPLEMENTATION.md)。主操作黄色、深灰蓝导航、表格密度和图形沿用原型，不默认改成shadcn灰白外观。通过主题token和组件组合实现外观，保留键盘焦点和禁用语义。
- 保留原型导航顺序、页内 Tabs、模块出现顺序、图表种类/图例色标/分组、表格列序/淡色分组、抽屉和弹窗宽度。统一组件不得把图表改成简表、把 Tabs 改成长页锚点或省略模块。
- 实施前检查V20完整HTML及v20-parts最终覆盖；分配明细表头恢复V17是用户指定例外，其余流程继续V20。组织页四组结构与SD/RSM联动、稳定Actual图和较上版万元差均须保留。
- Dialog 保留标题、说明、焦点约束、Escape、取消无写入及关闭后焦点恢复。图标按钮必须提供可访问名称；表单 label 与控件关联，错误不能只依赖颜色。
- 表格沿用 TanStack 的排序、筛选和分页能力，使用共享 Table 呈现；长表在容器内滚动，保留可访问的标题、表头与数值对齐。
- 普通排版容器、业务图形和已归档原型不要求转换成 UI 基础组件。归档原型只作证据，不当作生产组件来源。
- 不引入 Ant Design、Fluent UI 或其他重复组件库。若组件选择会改变交互或业务含义，提出具体方案请用户确认；调整完必须给出可审阅结果，请用户确认效果。

## 业务与数据

- API 模式失败必须显示错误，不能回退到 demo 数据。Portal 入口强制真实 API，会话与 CSRF 逻辑不得绕过。
- Owner 三步编辑、保存草稿、部门确认后冻结、部门齐交提交、部门撤回与管理员全版本驳回的差别必须保留；管理层仅统计已确认快照。
- 用户所属 Sector/Department 与业务授权范围分别显示和维护；受限历史费用不得先送至浏览器再隐藏。
- PPP是误加占位，页面、提示、抽屉、导出均取消；不再新增独立销售target需求。缺失的经销商target和业务期间显示未提供；Phasing直接读源phasing_2025/phasing_2026，源空不回算；季度刷新不代表已覆盖某月。
- 本批真实PG销量/C3/费用已由用户确认至9月；所有页面与抽屉透传state.ytdCutoffMonth。源批次确认失效时该值为null，显示“截止月待确认”，不能默认回退10月。管理员编辑configuredYtdCutoffMonth，本地10月合成数据不改为真实口径。
- 经销商、项目、资源大类、组织与试算方法下钻须打开真实详情抽屉，保持当前范围、版本与期间；内层可返回，关闭恢复焦点，不能用静态名称或跳转编辑页代替只读详情。
- 依据 [V2.0指标映射](../docs/METRIC_DEFINITIONS.md) 统一组合/编辑页：合同、Vol显示KL，金额历史显示K$；Phasing源比率乘100展示（0有效、缺失保留空）；Yield两项>0，YoY基期≤0显示“无基期”。Phasing汇总按同年源target加权源Phasing，不能简单平均；缺失权重不伪造。其他聚合比率先求和再除。
- 试算负权归0、总权0不能计算；不能偷偷均分或据此改写源负数。YTD配置1–12默认10只调整配置标签，数据来源仍显示各自实际覆盖或“未提供”。V2.0已知算法的工程差异直接修复，不伪装成待业务确认。
- Excel 读写继续在按需模块 Worker 内执行。取消导入不写入，确认前保留错误检查、版本和身份校验。
- 统一通过现有 `workbench/api.js` 与 Portal 请求封装访问后端；前端不持有 PG、Databricks 或模型密钥。

组件迁移还需浏览器检查桌面和窄屏、键盘焦点、选择与输入、表格滚动、弹窗、取消和提交结果；不要仅凭截图判定流程正确。不要提高包体阈值或引入 ExcelJS 主线程副本来绕过检查。测试、构建和截图须对应本次修改后的代码。

## 2026-11-17 版本规则修订

本条替代上述部门齐交才可关闭及多版本独立开放规则：管理员可随时停用版本；发布、重新发布或驳回重开时，原子停用其他开放版本，跨年度最多一个版本开放提交。停用保留分配、提交及部门确认；重新发布不自动撤销部门确认。界面采用发布／停用。


2026-11-17 版本编辑补充：修改版本名称、截止时间不改变发布/开放状态，不修改已有分配和提交确认；已开放版本延后或清空截止时间后恢复允许操作，但显式停用及部门确认锁不被绕过。项目配置与批量导入也保留版本原发布/开放状态，不再使整个版本退回未发布；涉及预算/归属等配置变化仍按原规则标记受影响项目须重提并撤销相关部门确认。停用及切换开放版本由管理员显式操作。
