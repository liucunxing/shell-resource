一句话定位

一个可以自动生成预算初始方案、允许在线反复调整、即时解释组合影响，并持续追踪实际花费的Distributor投资决策工作台。
中文为主在线多人使用实时Insight规划与Tracking闭环

核心问题

预算分给谁、为什么这样分、是否存在结构性风险、还有多少尚未分配、调整会带来什么影响，以及实际执行是否符合计划。

功能需求

点击标题折叠或展开

FR-01 数据导入与校验−
  • 导入历史表现、2027 Plan Budget、Initiative适用Distributor关系和季度Actual Spend。
  • 校验必填维度、重复记录、非数字金额、负数及维度映射。
  • 历史数据按Distributor × Resource Type识别，不按Department作为最细粒度。
FR-02 Initiative适用Distributor范围−
  • 以导入的适用关系为基础，系统结合历史数据提供候选推荐，用户可增删。
  • 每个Initiative维护独立范围，并允许保留新增Distributor预算池。
FR-03 自动初始拆分−
  • 用户逐Initiative选择按2026全年Vol或C3拆分。
  • 指标为0或缺失时，在适用Distributor范围内平均分配并标记依据。
  • 金额取整到元，不允许负数，尾差补到占比最高的Distributor。
FR-04 在线调整与实时重算−
  • 核心功能包括逐行修改、锁定后重算、Distributor间预算转移。
  • 每次调整同步刷新待分配金额、待分配比例及全部Insight。
  • 保留原始金额、当前金额、变化额、变化比例及修改状态。
FR-05 待分配池与版本确认−
  • 每个Initiative独立维护待分配金额、比例、原因和后续状态。
  • 最终版本可保留待分配预算，但必须明确列出，不隐藏为差额。
  • 正式版本成为2027 Tracking基线，并保留后续变更记录。

集中度

查看单一Distributor占比、Top N及组合集中度。

组合叠加

跨部门或多Initiative重复投入

识别同一Distributor获得多类资源的情况。

趋势匹配

投入增幅与Vol/C3增长不匹配

评估2027投入变化与历史业务趋势之间的偏离。

预算完整性

待分配比例过高

按Initiative、Department和Sector展示未明确到Distributor的预算。

Insight输出要求

每条结论包含严重程度、分析视角、触发规则、受影响对象、关键数字和建议复核方向；随着调整实时更新，失效结论自动移除。

2027季度Actual Spend Tracking

以确认版预算为Plan Baseline

Tracking粒度

Quarter + Distributor + Department + Initiative，并支持Sector汇总。

核心指标

  • Plan Budget / Actual Spend
  • Remaining Budget / Utilization %
  • Forecast Spend / Variance

Yield

2027预计C3为Distributor级，同时计算Plan Yield和Actual Yield。

Plan Yield = 预计C3 / Plan Resource　　Actual Yield = Actual C3 / Actual Resource

数据结构与计算规则

更新后的建议字段

数据集关键字段用途
历史表现Year, Quarter, Distributor, Resource Type, Vol, C3, Resource计算历史Yield、趋势、波动和初始拆分权重。
2027预算总盘Sector, Department, Resource Type, Initiative, Plan Budget定义各Initiative预算及资源属性。
适用范围Sector, Department, Initiative, Distributor, Applicable Flag控制可参与分配的Distributor。
分配方案Version, Sector, Department, Resource Type, Initiative, Distributor, Basis, Plan Amount, Unallocated Amount保存初始拆分、调整和待分配池。
2027 TrackingQuarter, Distributor, Department, Initiative, Actual Spend, Actual C3追踪执行、差异、使用率和Yield。
C3 Yield = C3 ÷ Resource。 Resource为0或缺失时显示“无法计算”，不默认显示为0。
预算关系： Initiative Plan Budget = 已分配至Distributor金额 + Initiative待分配池金额。

产品原则

工具提供一致口径、可解释初始方案和调整影响分析，不替代业务作出最终投资决定，也不将历史投入与业绩简单解释为因果关系。
