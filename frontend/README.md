# 资源投资工作台前端

依据 `prototypes/` 中客户 Demo / 需求 V1.1 独立实现的 React 前端。六个业务页面均可操作，原始 HTML 保持原样。所有工程变更位于 `frontend/`，未修改或调用后端。

## 本地运行

Node.js 22.12+ 或 24，npm：

```powershell
cd frontend
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。构建与检查：

```powershell
npm test
npm run build
npm run preview
```

预览默认 http://127.0.0.1:4173 。`dist/` 可部署到静态服务器；使用 hash 路由，无需业务 API。原型目录随构建复制，以保证「客户原始 Demo」链接可用。新前端运行资源全部本地打包；客户原始 HTML 自身的 CDN 依赖未改动。

## 小One问数Agent 面板（二期预留）

全局入口与面板显示名为「小One问数Agent」，底层预留嵌入易问产品的问数界面。默认未配置地址，只展示未接入状态，**不生成 iframe**。桌面展开后，面板从左侧导航右缘延伸至窗口右端，覆盖整个业务内容区，便于查看 Insight；手机采用全屏面板。

接入时复制 `.env.example` 为 `.env.local`，填写 `VITE_YIWEN_IFRAME_URL` 并重启开发服务；静态部署需重新构建。该值是会进入浏览器构建产物的**公开 URL**，不能放密钥、密码或认证 token。地址须为 HTTPS；仅 `localhost`、`127.0.0.1`、`[::1]` 允许 HTTP 本机调试，拒绝含用户名或密码的地址。

配置有效地址后，iframe 在首次展开时加载；折叠和业务切页保留同一个 iframe，避免重复加载问数会话。刷新整个页面会重新初始化。当前不向易问传递预算数据，也不实现 `postMessage` 通信或账号、部门权限映射。

正式接入前，须验证易问服务的 CSP `frame-ancestors`、`X-Frame-Options`、企业 SSO 和跨站 cookie 策略；当前预留面板不代表这些能力已连通。浏览器触发 iframe 的 `load` 事件也不能单独证明服务、登录或权限验证成功。

## 数据与边界

- 首次打开载入**合成示例**：7个项目、3部门、4个Sector。2026全年历史、2027预算/预计/实际均为演示数据，不是客户数据；顶部持续标注。
- 可以恢复示例，或清空后录入自己的数据。清空/恢复需二次确认。数据仅保存在本机浏览器 `shell-resource-workspace-v1`，不具备企业认证、服务端权限或多人协同。
- 金额使用非负安全整数元。每项目 `总预算 = 已分配 + 独立待分配池`；编辑金额同步增减池。转移限同项目，锁定行不参与编辑/转移，重算保留锁定金额。
- 取整采用最大余数分配，保证小额多对象场景非负且守恒。与客户原型的「四舍五入后尾差补首行」有意不同，避免负数尾差。
- 全员存在有效历史且权重全为零时均分并标注。部分缺失/负权重阻止生成，提示补齐或停用对象；不把未知值静默当零。FY优先取FY行，没有FY时只允许完整四季度合成，不重复相加。
- 修改上游信息撤销相关分配/确认；金额或说明变更撤销相关确认。池大于零必须填写原因。全部项目、部门确认且金额逐项平衡后才可发布；本机发布保存独立深拷贝，后续编辑不覆盖它。
- Tracking固定为**选定季度YTD快照**，不会累加Q1与Q2。缺少实际明示缺失；汇总实际仅为已导入值，剩余/使用率相应提示不完整。全年预测不齐时不展示伪造总额。
- Insight 当前为可解释演示规则：项目平衡、池原因、集中度45%、变化30%缺解释、池比例20%、全零均分提示。阈值待业务确认；六类完整业务Insight、项目级C3/Yield归因不宣称已完成。
- 当前预计C3为经销商级，暂不将它复制到项目计算Yield。未接Databricks、DataAgent、真实账号和后台。

## Excel 契约

只支持 `.xlsx`，最大10MB；`.xls` 请先另存为 `.xlsx`。使用原 Demo 的表头，下载模板后填写。先显示数量、样本/错误，再确认整批写入；出现非法数字、负金额、重复或关联错误时整批拒绝。预算、历史和预计导入替换对应数据集；Tracking按项目/经销商/季度合并，保留其他季度。

适用名单严格限当前项目；调整表严格限当前部门，须包含当前部门全部分配记录，不允许修改初始金额或锁定金额。调整表 `UnallocatedAmount` 在同项目每行重复显示该项目池金额，导入时要求一致，**不可逐行求和**。适用名单启用状态为前端功能，原 `Source` 模板导入默认启用。旧客户原型导出的调整表（池仅放第一行）请先按新工作台导出的表进行调整。

## 工程结构

- `src/pages/`：六个页面，按页面延迟加载。
- `src/components/ui.tsx`：通用表格、金额输入、状态、指标与洞察。
- `src/domain/`：类型、合成数据、纯计算和状态转换、Excel适配。
- `src/state/WorkspaceContext.tsx`：本机状态、持久化、通知、hash导航。
- `src/styles.css`：浅色企业工作台样式、响应式与 reduced-motion。
- `tests/`：金额守恒、确认/版本、YTD与Excel校验测试。
- `output/playwright/`：本地浏览器检查与截图（不进入Git）。

UI使用官方 Fluent UI 9、TanStack Table 8、Phosphor 图标；React + TypeScript + Vite。按用户指定 Taste 技能采用保留式改造，参数为设计变化3、动效2、信息密度6；业务工作台不应用营销页大图和滚动特效。[Fluent UI](https://react.fluentui.dev/) / [TanStack Table 8](https://tanstack.com/table/v8/docs/framework/react/react-table)。

ExcelJS 延迟加载，首次导入/导出时加载较大解析包。ExcelJS 仅调用 uuid v4，已覆写至兼容的 uuid 11.1.1+以去除旧版本依赖告警；浏览器导入导出须纳入回归。当前前端不是生产发布审批或后端安全边界。
